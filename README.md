
## think-orm 4.0
基于PHP8.0+ 和PDO实现的轻量级ORM，完全重构的Model层，支持实体模型和分层（[新特性盘点](https://doc.thinkphp.cn/@think-orm/v4_0/new-features.html)）

基于版本 https://github.com/top-think/think-orm/tree/v4.0.51

文档地址 https://doc.thinkphp.cn/@think-orm/v4_0/default.html

### 安装

~~~
composer require ibibicloud/think-orm
~~~
